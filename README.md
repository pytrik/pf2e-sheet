# PF2e Character Sheet Builder

**[Try it live](https://pytrik.github.io/pf2e-sheet/)**

A single-page application for creating clean, readable Pathfinder 2nd Edition character sheets. The app compiles to a single HTML file for easy distribution and offline use.

## Overview

The app presents a two-panel interface: an input form on the left and a live A4 sheet preview on the right. Character sheets are divided into two pages — the first covering core stats, skills, and attacks, the second covering abilities, spells & alchemical formulas, and items.

Key stats (AC, saves, skills, class DC, spell DC, attack bonuses, HP) are auto-calculated from ability modifiers and proficiency levels, with optional misc bonus fields for house rules and item bonuses. The app does not enforce game rules or include game data beyond the standard skill list, making it fully compatible with homebrew content.

## Tech Stack

- **Svelte 5** — UI framework (components still use the Svelte 4 syntax, which Svelte 5 runs in legacy mode)
- **TypeScript** — type safety
- **esbuild** — bundling to a single HTML file
- **No runtime dependencies** — everything compiles down to one self-contained HTML file

## Features

- Live preview of a two-page A4 character sheet
- Auto-calculated stats with proficiency selection and misc bonus fields
- Full PF2e skill list with automatic bonus calculation
- Abilities list with type tags and optional level indicators
- Attack entries with auto-calculated bonuses
- Spells and alchemical formulas: one or more sources per character — spellcasting (tradition, DC, attack, slots per rank) and formula books (known formulas by item level, per-day count)
- Item inventory with weight, value, amount, and remaining uses tracking
- Auto-calculated HP (class + CON + ancestry + extras)
- Three render modes: **Standard** (spacious two-page A4), **Dense** (compact two-column), and **Mobile** (compact single-column, auto-activates on narrow screens)
- localStorage auto-save with JSON export/import
- Import characters from Pathbuilder 2e ("Export JSON")
- Share characters via URL — compresses character data into the link, no server needed
- Browser-native printing with print-optimized CSS
- Clean, minimal sheet design with toolbar icons

## Getting Started

```bash
npm install
npm run dev      # development server with live reload
npm run check    # type check (svelte-check)
npm run build    # production build → dist/index.html
```

## Usage

1. Open the app in a browser
2. Fill in character details using the input form on the left
3. Preview the rendered sheet on the right in real time
4. Use **Export** to save character data as JSON, **Import** to load it back — Import also accepts a Pathbuilder 2e JSON export
5. Click **Share** to copy a URL containing your character — anyone who opens it loads the sheet instantly (asks first if it would replace a character already saved in that browser)
6. Print via Ctrl+P — the preview is styled for clean A4 output
